**Key correction from roadmap:** The roadmap specified `@mariozechner/pi-coding-agent` for the agent harness. That package is a CLI terminal app with a full TUI — wrong for Electron embedding. The correct packages are:

- `@mariozechner/pi-ai` — unified LLM provider abstraction, OpenRouter built-in, `getModel()`

Run 4 (echo streaming) is dropped. Pi's event system maps cleanly onto IPC, so building echo mode first adds throw-away code with no real validation benefit.

## Run 4/5 (merged) — Chat UI + Pi SDK + OpenRouter Streaming

### Package installs

```bash
bun add @mariozechner/pi-ai @mariozechner/pi-agent-core
```

### Agent session wrapper

**`src/main/agent/session.ts`** — `AgentSession` class:

- Wraps one Pi `Agent` instance
- Constructor accepts: `win: BrowserWindow`, `messageService: MessageService`, `projectId: string`, `model: Model`, `apiKey: string`
- `send(content: string)` — persists user message via `messageService.addMessage()`, then calls `agent.prompt(content)`
- `abort()` — calls `agent.abort()`
- Subscribes to Pi agent events on construction:
  - `message_update` + `assistantMessageEvent.type === 'text_delta'` → `win.webContents.send(IPC.MESSAGE_CHUNK, delta)`
  - `agent_end` → find the last `assistant` role message from `event.messages`, persist its text content via `messageService.addMessage()`, then `win.webContents.send(IPC.MESSAGE_DONE)`
- Pi `Agent` initialized with `beforeToolCall` hook that always returns `{ block: true, reason: "Tools not available until Run 6" }` — safe placeholder until tools are wired

**Session lifecycle in `ipc-handlers.ts`:**

```
Map<projectId, AgentSession>  (module-level, lives as long as the window)
```

- `SEND_MESSAGE` handler: resolve `SettingsService` from container to get current `apiKey` + `model`; look up or create `AgentSession` for `projectId`, call `session.send(content)`
- If no API key configured: send `MESSAGE_DONE` with an error message to renderer instead of creating a session
- Session created lazily on first message; reused for subsequent messages (preserves Pi conversation history per project)
- Session destroyed when project is deleted (future work)

### IPC contract additions

New channels added to `src/shared/ipc-channels.ts`:

| Channel | Direction | Pattern | Purpose |
|---|---|---|---|
| `GET_MESSAGES` | renderer→main | `invoke` | Fetch message history for a project |
| `GET_SETTINGS` | renderer→main | `invoke` | Read current settings (model, has API key) |
| `SAVE_SETTINGS` | renderer→main | `invoke` | Save API key + model choice |

### Settings service

**`src/main/services/SettingsService.ts`** — `@injectable()`:

- Stores settings in `app.getPath('userData')/settings.json`
- API key encrypted via `electron.safeStorage.encryptString()` before write; decrypted on read
- Model string stored plain (not sensitive)
- `getSettings(): Promise<{ openrouterApiKey: string | null; model: string }>`
- `saveSettings(patch: { openrouterApiKey?: string; model?: string }): Promise<void>`
- Registered in DI container in `bootstrap.ts`

### UI components

**`LeftSidebar`:**
- Fetch project list via `GET_PROJECTS` on mount
- "New project" button → inline name input → `CREATE_PROJECT` → refresh
- Click to select active project (state lifted to `App.tsx`)
- Active project highlighted
- Gear icon in footer → opens Settings modal

**`ChatPanel`:**
- On project select: fetch messages via `GET_MESSAGES` → render history
- If no API key: show inline prompt "Configure OpenRouter API key in Settings" instead of input
- Message list: user messages right-aligned, assistant left-aligned
- Streaming: listen for `MESSAGE_CHUNK` → accumulate into live assistant bubble; `MESSAGE_DONE` → finalize
- `MessageInput`: textarea + send button + model selector chip

**`MessageInput`:**
- Reads current model from settings (fetched on mount via `GET_SETTINGS`)
- Model selector chip — click to open small dropdown with a few OpenRouter model options
- On send: fires `SEND_MESSAGE` (fire-and-forget), optimistically appends user message to local state

**Settings modal:**
- API key field (masked, type=password)
- Model selector dropdown (default: `anthropic/claude-sonnet-4-6`)
- Save → `SAVE_SETTINGS` IPC
- Accessible via gear icon in LeftSidebar footer

### Default model

`anthropic/claude-sonnet-4-6` via OpenRouter.
